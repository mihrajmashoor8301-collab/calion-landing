# CALION — Main Ecosystem Landing Website

The official, centralized landing website for the **CALION** cybersecurity ecosystem (`endlessus.in`).

## Ecosystem Overview

- **CALION Academy:** [https://learning.endlessus.in](https://learning.endlessus.in) — Hands-on offensive security curriculum and lab workflows.
- **CALION Library:** [https://notes.endlessus.in](https://notes.endlessus.in) — Technical documentation, references, and command cheat sheets.
- **CALION Tools:** [https://tools.endlessus.in](https://tools.endlessus.in) — 13 zero-telemetry, client-side browser utilities.
- **CALION Quiz Platform:** [https://quiz.endlessus.in](https://quiz.endlessus.in) — Interactive knowledge assessments.
- **CALION Portfolio:** [https://portfolio.endlessus.in](https://portfolio.endlessus.in) — Project dossier and research (planned).

## Architecture

- Lightweight, zero-framework static HTML, CSS, and JavaScript.
- Zero external font CDNs, trackers, or telemetry.
- Strict Content Security Policy (CSP), HSTS, and modern security headers.
- Deployed on Cloudflare Pages.
